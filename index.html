Start with the basics

Your first learning sequence

A practical order for beginners. Take your time and practise each concept.
LESSON 01

Ethics, permission & safety

Know the boundaries before touching any system.

  1. What cybersecurity means
  2. Difference between ethical and unauthorized access
  3. Permission, scope and responsible disclosure
  4. Protecting personal information
LESSON 02

Computer & operating system basics

Understand the machines you want to protect.

  1. Files, processes and memory
  2. Users and permissions
  3. Windows and Linux concepts
  4. Command-line basics
LESSON 03

Networking fundamentals

Learn how devices communicate.

  1. IP addresses and DNS
  2. Ports and common protocols
  3. Routers, switches and firewalls
  4. Basic network troubleshooting
LESSON 04

Start coding with Python

Build simple programs before automating tasks.

  1. Variables and data types
  2. Conditions and loops
  3. Functions and files
  4. Small, safe automation projects
Learn by doing

Safe practice lab ideas

Use intentionally vulnerable training environments and your own test projects only.

Lab A — Build a secure password checker

Write a small program that checks password length and basic strength rules. Do not collect or store real passwords.

# Simple password-length exercise password = "example-only" if len(password) >= 12: print("Length requirement met") else: print("Choose a longer password")

Lab B — Inspect your own website

Review your page for HTTPS, clear privacy information, accessible labels, updated software and safe form handling.

Security review checklist [ ] HTTPS enabled [ ] Software updated [ ] Strong account passwords [ ] Multi-factor authentication [ ] No exposed private data

Phase 1 · Foundations

Computer basics, networking, Linux, ethics and Python fundamentals.

Phase 2 · Choose a specialty

Explore web, network, cloud, mobile, blue-team or governance security.

Phase 3 · Build evidence

Complete legal labs, document projects and create a portfolio of your learning.

Phase 4 · Prepare for work

Practise communication, report writing, interview skills and relevant certifications.
